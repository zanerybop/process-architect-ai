# Ограничения

- Каталог BPMN 2.0.2 используется для построения и сохранения документов.
  Исполняющего движка нет; все комбинации элементов не проверены.
- bpmn-js используется для совместимых процессов. При потере данных в пробном
  round-trip остаётся документный редактор; хореографии и разговоры используют его.
- Структурная корректность, XSD, поведение, качество раскладки и соответствие
  бизнес-описанию — разные проверки. Успех одной не означает успех остальных.
- Полный анализ поведения сложных конструкций может вернуть `inconclusive`.
  Локальные найденные дефекты обычного XOR/AND control flow не скрываются этим статусом.
- Привязка элементов к цитатам и узкие смысловые проверки помогают аудиту,
  но не гарантируют полноту действий, ролей и условий. Нужна проверка аналитиком.
- LLM может ошибаться или нестабильно поддерживать формат ответа. Реальная модель
  и совместимость endpoint проверяются отдельно от unit-тестов. Автоматического
  переключения live на демонстрационные данные нет.
- Mock принимает только точный известный текст. Новый текст возвращает явную ошибку.
- Раскладка детерминирована для одного IR. Для произвольного графа отсутствие всех
  пересечений и удобство чтения при масштабе «Вписать» не обещаются.
- Несохранённые правки хранятся в памяти вкладки. Для долговременного хранения
  используйте сохранение ревизии или экспорт. Совместного редактирования нет.
- Примеры и корпуса в репозитории синтетические. Они не являются корпусом
  реальных закрытых регламентов и не доказывают общее качество модели.
- Зависимости закреплены lock-файлами. Docker-образы заданы тегами, поэтому
  повторная сборка не гарантирует побайтово одинаковый образ.
- Локальные аккаунты не заменяют настройку безопасности открытого сервиса.
  Подробности — в [SECURITY](SECURITY.md).
