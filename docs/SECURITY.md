# Безопасность

Сгенерированная программа, описание процесса и импортируемый XML считаются
недоверенными данными. Внешний текст не является инструкцией оператору системы.

## Выполнение

AST-интерпретатор принимает только разрешённые вызовы BPMN Builder с литеральными
аргументами. Импорты, вычисления произвольного Python, файловая система,
сеть и `exec/eval` не предоставляются программе. API не исполняет её в своём процессе.

Worker запускается отдельным контейнером без LLM-ключей и host mounts, в закрытой
сети. Он использует непривилегированного пользователя, read-only файловую систему,
ограниченный tmpfs, снятые capabilities, `no-new-privileges`, лимиты CPU, памяти
и процессов. Дочернее выполнение дополнительно ограничено по времени и памяти.
При недоступном worker возвращается явная ошибка, а не локальный fallback.

Описание ограничено 20 000 символами, программа — 65 536 байтами. Документный
Builder допускает до 1 200 вызовов и 2 500 элементов. Базовый профиль API 1.0 имеет
дополнительные собственные ограничения. Официальные XSD загружаются локально;
XML-парсер не разрешает произвольные внешние сущности и сетевую загрузку схем.

## Доступ и секреты

Пользователи создаются оператором через `backend.app.manage_users`; публичной
регистрации и HTTP-маршрута создания аккаунтов нет. Пароли вводятся скрыто или
через stdin, а не через аргументы командной строки. Сессии хранятся на сервере,
отзываются при выходе и ограничивают доступ к генерациям и ревизиям владельца.

Cookie и CSRF-проверки защищают рабочие API. При HTTPS нужно включить
`AUTH_COOKIE_SECURE=true`. Compose по умолчанию публикует порты только на loopback.
Файлы `.env`, учётные данные, сессии и `local_data/` исключены из Git.

Ключ провайдера хранится только в серверной конфигурации и не передаётся frontend
или worker. Описания процессов отправляются выбранному LLM-провайдеру в live-режиме:
получите разрешение владельца перед обработкой закрытых данных.

## Граница гарантий

Это прототип для контролируемого использования. SSO, восстановление пароля,
полноценная эксплуатационная защита открытого сервиса и независимый production
security review не реализованы. Ограничения интерпретатора не заменяют изоляцию
контейнера, а корректный XSD не доказывает безопасность бизнес-логики.
