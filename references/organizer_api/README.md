Документ называет интерфейс примером фреймворка, который участники реализуют
самостоятельно. Проект сохраняет собственный ограниченный API. Синтаксическая
совместимость с `DIAGRAM` не заявляется.

Таблица ниже описывает исходный профиль **API 1.0**. Документный API 2.0
дополнительно поддерживает стандартные типы каталога XSD, включая подпроцессы,
scriptTask, inclusiveGateway и группы. Это не добавляет исполнение скриптов
или синтаксическую совместимость с `DIAGRAM`.

| Пример организаторов | Контракт проекта 1.0 | Различие |
|---|---|---|
| `ROOT_PROCESS_ID`, `ROOT_START_TASK_ID`, `ROOT_END_TASK_ID` | `bpmn.process/start/end` | Явное создание с заданными ID; несколько конечных событий разрешены |
| `DIAGRAM.add_task` | `bpmn.task(kind="task")` | Именованные литеральные аргументы, ID задаётся явно |
| `DIAGRAM.add_user_task` | `bpmn.task(kind="userTask")` | Та же семантика задачи, другой синтаксис |
| `DIAGRAM.add_pool` | `bpmn.pool` и `bpmn.lane` | Пул и дорожки задаются отдельно; процесс явно принадлежит пулу |
| `DIAGRAM.add_link` | `bpmn.flow` / `bpmn.message_flow` | Sequence flow и message flow различаются явно |
| `DIAGRAM.add_exclusive_gateway` | `bpmn.xor_gateway` | Условия и default задаются у потоков |
| `DIAGRAM.add_parallel_gateway` | `bpmn.parallel_gateway` | AND без условий на выходах |
| `DIAGRAM.add_script_task` | Не поддерживается | Выполнение скриптов не входит в профиль |
| `DIAGRAM.create_subprocess` | Не поддерживается | Подпроцессы не входят в профиль |
| `DIAGRAM.add_inclusive_gateway` | Не поддерживается | Inclusive gateway не входит в профиль |
| `DIAGRAM.add_group` | Не поддерживается | Группы не входят в профиль |

Оригинал использует позиционные аргументы, присваивание возвращённых ID,
переменные и распаковку пары для пула/дорожек. Проект принимает только отдельные
вызовы `bpmn` с литеральными именованными аргументами. Расширять грамматику или
использовать `exec` ради запуска этого примера не требуется: требование задания —
генерируемый моделью Python для самостоятельно реализованного интерфейса.
