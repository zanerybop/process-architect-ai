# Происхождение и права

Источник схем: Object Management Group, нормативные машиночитаемые материалы
[BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/), OMG file ID `dtc/10-05-04`.
Файлы скачаны без изменения. В самих пяти XSD отдельного текста лицензии нет.

Сведения об авторских правах, лицензиях и ограничениях использования приведены
на страницах 2–3 [официальной спецификации OMG formal/2013-12-09](https://www.omg.org/spec/BPMN/2.0.2/PDF)
и в [юридических уведомлениях OMG](https://www.omg.org/legal/).
