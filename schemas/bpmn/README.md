# Официальные схемы BPMN 2.0.2

Локальная неизменённая копия пяти нормативных XSD, перечисленных на
[странице OMG BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/), получена 2026-09-28.
Базовый URL файлов: `https://www.omg.org/spec/BPMN/20100501/`.
Дата `20100501` в URL относится к нормативному набору, на который ссылается версия 2.0.2.

Входная схема — `BPMN20.xsd`. Она импортирует `BPMNDI.xsd` и включает
`Semantic.xsd`; `BPMNDI.xsd` импортирует `DC.xsd` и `DI.xsd`; `DI.xsd`
импортирует `DC.xsd`. Все ссылки изначально относительные и разрешаются внутри
этого каталога. Схемы не исправлялись и не подменялись упрощённой схемой.
При проверке входного XML сетевой доступ и DTD должны быть отключены.

а не исходники проекта под его лицензией.
